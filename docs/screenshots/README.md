# 증빙 자료

제출 패키지 5번 항목(증빙 자료)을 이 폴더에 넣습니다.

## 1) 서비스 스크린샷 1세트

배포 URL(https://mood-pairing-gamma.vercel.app)에서 캡처합니다.

| 파일명 | 내용 |
|---|---|
| `desktop-home.png` | 데스크톱 — 홈 화면 |
| `desktop-result.png` | 데스크톱 — **AI 기능 동작 장면** (검색 결과가 표시된 상태) |
| `mobile-home.png` | 모바일 — 홈 화면 |
| `mobile-menu.png` | 모바일 — 햄버거 메뉴를 연 상태 |

모바일 캡처는 실제 휴대폰으로 접속하거나,
브라우저 개발자 도구(F12) → 기기 툴바(Ctrl+Shift+M) → 폭 375px로 맞춰 찍으면 됩니다.

## 캡처 시 주의

**API 키가 화면에 보이지 않도록 주의하세요.**

터미널에 출력된 키 문자열 등이 캡처에 포함되지 않아야 합니다.
